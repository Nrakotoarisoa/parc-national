# Parc National

Frontend React TypeScript pour une plateforme touristique de parc national: exploration des zones, activités, avis, réservation client et back office admin.

## Stack

- React TypeScript + Vite
- TailwindCSS + composants Shadcn-style
- Redux Toolkit + RTK Query
- Axios
- Framer Motion
- React Hook Form + Zod

## Commandes

```bash
npm install
npm run dev
npm run build
```

## Configuration

Créer un fichier `.env` à partir de `.env.example`:

```bash
VITE_API_BASE_URL=http://localhost:3000
```
